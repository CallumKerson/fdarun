# Security policy

fdarun hands out Full Disk Access, so bugs that let a process get it without
being allowed matter.

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/CallumKerson/fdarun/security/advisories/new),
not in a public issue. Only the latest release is supported.

The [threat model](README.md#threat-model) lists what fdarun does not protect
against; reports about those are still welcome if you see a way to close them.
